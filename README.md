# dsh-recent-sessions

在 DSH 侧边栏工作区下方增加可折叠的「最近」分组，跨项目汇总近期会话，支持重命名/分叉/归档；会话跑完后可发 Windows 桌面通知。设置页名为「最近会话」。

## 功能

- **位置**：侧边栏底部的增补插槽 `sidebar.footer.action`，在工作区浏览区之下、Settings 之上，不覆盖任何原有侧边栏区域，也不修改 DSH 自身代码。
- **汇总与排序**：跨全部工作区、排除归档与子智能体会话，先置顶、再按最近活动时间倒序，时间相同以会话 ID 稳定保序。
- **折叠**：点击「最近」标题折叠/展开。
- **排序入口**：标题右侧的排序按钮，目前只有「最新」一项，默认选中，为后续排序方式预留了位置。
- **条目表现**：标题、相对时间、运行转圈、待审批/待回答的亮点、选中态都复用原工作区会话行的判定与视觉（自有的类名前缀 + `--dsw-*` 主题 token，不依赖任何 DSH 内部模块）。
- **所属项目**：悬停会话显示所属工作区（项目）名称；键盘聚焦同样可读到（`aria-description`）。
- **分批显示与高度**：「默认显示条数」决定首批渲染多少条；超出后点「再显示」按可配置步长分批增加，默认每次 20 条，不会一次把所有会话塞进 DOM；全部显示后按钮变成「收起」。显示高度默认 5 条，超出部分在列表内滚动。
- **完成提醒（可选）**：后台会话跑完后发一条 Windows 桌面通知，见下节。
- **会话操作**：鼠标移到任意行，右端依次出现「⋯」「归档」「置顶」三个按钮，与工作区会话行完全一致；「⋯」里是置顶 / 重命名 / 分叉会话 / 归档会话。
- **文件右键菜单**：助手回复里被渲染成文件卡或文件链接的路径（行内 `@path` 引用、Markdown 文件链接、交付文件卡片、改动文件卡片的行），右键弹出 DSH 原生样式的文件菜单：打开文件、在资源管理器中打开、在右侧栏打开、打开方式、另存为…、复制路径、复制文件内容。左键行为不变。见下节。

## 会话操作

「最近」的每一行照抄工作区会话行的结构与视觉：同样的 `Menu` 与 `MenuItemButton` 基元、同样的图标、同样的 10px 间距与 16×16 按钮，弹层位置、关闭方式、键盘上下走和焦点归还都一致。

- 静止时显示**相对时间**；已置顶的行额外显示一个常驻的实心图钉。
- 悬停时时间和图钉一起让位，换成三个操作按钮：**「⋯」菜单**、**归档**、**置顶**。
- 「⋯」菜单五项：**置顶 / 取消置顶**、**重命名**、**分叉会话**、**归档会话**、**复制 Session ID**。

「复制 Session ID」与原生会话行新增的那一项同位置、同文案、同图标，复制完整会话标识，不打开会话。

菜单里**不显示快捷键提示**。工作区那几项显示 `Ctrl+Alt+G` 之类，是因为那些命令作用于「当前主视图会话」；照搬到「最近」的行上会误导成「按了就能改这一行」。本插件也不注册任何快捷键，所以不会和工作区的绑定冲突。

置顶那一项是本节自己的置顶（见下节），**不写入 Harness 的置顶账本**；归档、分叉、重命名走 DSH 的公开能力，行为与工作区一致；复制 Session ID 走原语包的 `writeClipboard`，与工作区那一项调用同一个实现。

操作条的显隐机制也照抄原版：静止时 `display:none`，悬停**或菜单打开**时显示。后面这个条件不能省 —— 菜单是 portal 到 `document.body` 的，指针一进弹层就离开了这一行，`:hover` 随之失效；行上挂的 `dshRecent_rowMenuOpen` 类就是用来把锚点撑过这段空隙的。

## 「最近」自己的置顶

「最近」的置顶是**这个分组自己的排序偏好**：它只让会话在「最近」里排到最前，**不写入 Harness 的置顶账本**，因此不改变该会话在所属工作区里的顺序或置顶标记。

- 已置顶的行常驻显示实心图钉，悬停时换成可点的置顶按钮；点击不会打开会话（事件已阻止冒泡）。
- 菜单里的置顶项与行尾图钉按钮是同一个动作，共享同一份置顶集合。
- 置顶集合存在浏览器本地（`localStorage` 的 `dsh-recent-sessions:pins`），是「这台浏览器上的显示偏好」，不随会话日志同步，也不跨浏览器共享。

## 完成提醒（Windows 桌面通知）

后台会话跑完后，在 Windows **右下角弹出系统通知**，横幅消失后仍留在通知中心。这是浏览器的 Web Notification 通道，不是网页内浮层 —— 所以浏览器最小化时照常弹出，不会因为看不见页面而错过。

- **默认关闭**，由设置页「完成提醒（Windows 桌面通知）」开关控制，存在 Loader 行的 `desktopNotify` 里。
- **触发口径**：只有「运行中 → 停止」的那一次跳变才提醒。与侧边栏「最近」的行用的是同一套过滤 —— 当前前台正在看的主会话不提醒（你正盯着它停），子智能体会话不提醒（那是它父会话内部的事，单独弹一条只会把你点进一个子对话），空白会话和已归档会话同样不提醒。
- **点击通知**会聚焦浏览器窗口并直接打开对应会话。
- **同一会话复用一条通知**（浏览器 `tag`），反复修改重跑只会更新那一条，不堆叠。
- **首次开启需要一次授权**：浏览器只在用户手势里才肯回答权限请求，所以点开关的那一刻才会弹权限框。拒绝了就把开关留在关闭状态，并在设置页提示去地址栏左侧的站点设置里改。

## 文件右键菜单

助手回复里出现的文件引用，右键会弹出一个**跟 DSH 原生菜单同一套视觉**的文件菜单。它不是另画的样式：菜单和菜单项用的就是工作区行菜单那套 `Menu` / `MenuItemButton` 基元，所以弹层位置、贴边收敛、键盘上下走、Esc 关闭、点外部关闭、关闭后焦点归还都是原生行为。

- **触发范围**：正文里被渲染成文件卡/文件链接的路径 —— 行内 `@path` 引用、Markdown 文件链接（`[说明](相对或绝对路径)`）、`present` 交付文件卡片、改动文件卡片的文件行。只拦截这些元素的 `contextmenu` 并 `preventDefault`；其他地方照旧弹浏览器菜单，**左键行为完全不变**。
- **菜单项**（从上到下）：
  1. **打开文件**：用 Host 桌面默认应用打开（Session Remote 的 `openWorkspacePath`）。
  2. **在资源管理器中打开**：在系统文件管理器中定位文件（Session Remote 的 `reveal`）。
  3. **在右侧栏打开**：把文件预览开到右侧 Sidebar（和左键点文件引用是同一个预览页；工作区外的绝对路径也能打开）。
  4. **打开方式**：子菜单列出系统关联应用，默认应用带「（默认）」标注，选中后用该应用打开。这个列表在**展开子菜单时**才查（并按文件缓存），所以右键菜单本身立刻出现，不被这条查询拖慢。
  5. **另存为…**：浏览器支持时走系统保存对话框（`showSaveFilePicker`），否则退回下载。
  6. **复制路径**：复制 Host 解析后的绝对路径。
  7. **复制文件内容**：按 UTF-8 读取整份文件文本后复制；非文本文件会明确报错，不会复制乱码。
- **不可用项**：
  - Host 没有桌面（远程会话、无头部署）时，原生打开/打开方式/资源管理器定位这几项**直接不出现**；右侧栏打开、另存为、复制路径、复制内容仍然可用。
  - 文件已不存在（Host 文件服务取不到）时，菜单显示「文件不存在」，只保留「复制路径」。
- **提示**：复制、保存、打开失败等结果用原生的轻量 Toast 在引用旁边提示，不弹对话框。

## 设置页

「最近会话」页面包含：

1. **仓库标识**：构建时从本仓库 Git 读取的仓库名与 tag，不是写死的字符串。当前提交若恰好处于某个 tag 就显示该 tag，否则显示「未打标签（最近 tag 距离说明）」或短提交号；完全没有 Git 信息时显示「未知版本」，绝不伪造 tag。
2. **默认显示条数**：整数，范围 1–50，决定首批渲染数量。
3. **每次展开条数**：整数，范围 1–50，默认 20，每次点击只增加这一批。
4. **显示高度（会话条数）**：整数，范围 1–30，把该区域的高度限制为若干条会话。
5. **完成提醒（Windows 桌面通知）**：开关，默认关闭，见上节。

偏好存在本插件 Loader 行的 `config` 里（`defaultCount` / `expandStep` / `visibleRows`，上限 `maxCount` / `maxRows`），由 Host 的 `Config` schema 声明，所以用户覆盖能在插件升级后保留。Host 尚未加载某个字段时（例如改完 Host 半还没重启），该字段标为不可用，而不是让整次保存失败。

## 安装

```
dsh plugin --profile <profile> add github:JackGuo0310/dsh-recent-sessions#v0.5.6
```

安装后重启 DSH。左侧栏工作区下方即出现「最近」分组；设置在 设置 →「最近会话」；助手回复里的文件引用可以右键。

## 开发

```bash
npm install            # 只有一个依赖：@deepseek-ai/schemastery
npm run check          # 语法检查三个 JS 文件
npm run version:meta   # 重新生成 client.js 里的 Git 版本块
npm pack               # 打包前自动刷新版本块
```

发布新版本：改 `package.json` 版本号 → `npm run version:meta` → 提交 → 打同号 tag → 推送。

### 版本块为什么内联在 client.js 里

DSH 浏览器的模块表只解析平台种子模块、已物化模块和已注册的包工厂；同步的 `require('./version-meta.js')`
不在其中，而相对路径只能走异步分块加载器。所以 Git 元数据由 `scripts/gen-version.mjs`
在构建时写进 `client/client.js` 中 `// dsh:version-meta:begin` 与 `// dsh:version-meta:end`
之间的标记区域，区域之外请勿手工编辑。`npm run version:meta -- --check`
可在 CI 中校验该区域是否与 Git 一致。

## 已知限制

- 运行中的子智能体不会单列一条状态说明：DSH 的全局会话状态源只提供运行中、待处理交互和完成提醒，
  子智能体数量由工作区浏览器自行从各工作区的目录推导。本插件沿用运行中转圈与待处理亮点。
- 折叠状态只保留在当前页面生命周期内，未做持久化。
- 桌面提醒依赖页面存活：DSH 没有 Electron 壳，关掉 DSH 页面或浏览器就没有提醒；页面开着但浏览器最小化则照常提醒。
- 通知挂在浏览器名下（图标为 Chrome/Edge），横幅停留时长与是否常驻由 Windows 通知中心设置决定，代码无法干预。
- 文件右键菜单只认「被渲染成文件引用」的元素：不带文件引用语义的纯文本路径不会命中；带预览的行内图片链接没有 `title`，也不命中。
- 「在右侧栏打开」打开的是文件预览页，和左键点文件引用完全同一个 tab 行为；它不改变左键本身。
- 「另存为…」和「复制文件内容」受 Host 文件服务的读取上限约束（默认整文件 32 MB、单页 2 MB / 5000 行），超限会提示失败而不是截断。
- 只支持 Chrome/Edge 一类 Chromium 浏览器才有的保存对话框；其他浏览器退回普通下载。
